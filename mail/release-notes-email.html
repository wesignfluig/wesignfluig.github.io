Novas funcionalidades

Inclusão de anexos no documento para assinatura
Agora é possível incluir anexos ao enviar um documento para assinatura eletrônica.

  • O remetente pode definir se deseja anexar documentos de apoio e classificá-los como Públicos ou Privados.
  • Os anexos não são assinados e devem ser utilizados apenas para complementar ou contextualizar o documento principal.
  • Anexos privados ficam disponíveis apenas para participantes pertencentes à organização (cadastrados no Portal WeSign).

Reenvio de documentos com status Enviando
O remetente do documento (ou um administrador do Fluig) pode realizar uma nova tentativa de envio diretamente pelo Quadro de Status quando ocorrer alguma falha na integração com o Portal WeSign.

Atualização do status dos assinantes
Também pelo Quadro de Status, o remetente (ou administrador do Fluig) pode sincronizar as informações dos assinantes com o Portal WeSign.

Novo dataset para tratamento de eventos (Callback)
Foi disponibilizado o dataset ds_callback_customizado_wesign, com código-fonte aberto para customizações. O dataset recebe todas as notificações do serviço de Callback, incluindo:

  • Documento Concluído;
  • Documento Recusado;
  • Documento Aprovado;
  • Documento Assinado.

Com isso, é possível implementar customizações em fluxo de processos que integram com o app WeSign, como movimentar uma solicitação após a assinatura de um documento.

Melhorias

Atualização do dataset ds_package_wesign
O dataset passa a consultar apenas documentos:

  • Enviados nos últimos 3 meses;
  • Com status Pendente;
  • Ordenados do mais recente para o mais antigo.
Para consultar documentos em períodos diferentes, utilize o formulário Utilitários WeSign (antigo Importador de Dados).

Atualização do dataset ds_upload_wesign
O reenvio de documentos para integração passa a ser realizado exclusivamente pelo formulário Utilitários WeSign, onde o administrador informa o período desejado para processamento. Além disso:

  • A sincronização automática foi desativada;
  • A execução agendada do dataset foi removida.
Com essa alteração, os usuários podem localizar documentos com falha de integração no Quadro de Status e realizar uma nova tentativa de envio de forma mais simples.

Atualização do formulário e processo customizado
O código-fonte do formulário e do processo customizado de integração com o app WeSign Fluig foi atualizado para:

  • Suportar a inclusão de anexos no envio para assinatura;
  • Modernizar o layout do formulário, mantendo o mesmo funcionamento já conhecido pelos usuários.
