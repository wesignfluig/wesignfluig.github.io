Parâmetros de Integração

Os parâmetros são obrigatórios na instalação a fim de definir todas as configurações iniciais necessárias para começar a utilizar o app. Abaixo encontra-se a descrição de cada campo.

  • Token: É uma string (sequência de caracteres) única, utilizada para representar a empresa e permitir o acesso aos webservices para integração no Portal de Assinaturas.
  • Usuário de integração: Usuário com perfil de administrador responsável por realizar as integrações entre fluig e Portal de Assinaturas.
  • Senha de integração: Senha do usuário de integração.

    Se houver alteração de senha do usuário, é necessário informar a senha atualizada e Salvar parâmetros.

    O app não irá permitir a utilização caso a senha informada esteja incorreta ou desatualizada.

  • Homologação: Marque esse campo caso o token utilizado seja do Portal de Assinaturas Homologação. Todos documentos enviados para a base de homologação não possuem validade jurídica.

Serviço de Integração Portal de Assinaturas

Ao clicar em Salvar parâmetros, será criado o serviço wesigner em Painel de Controle > Serviços.

Este serviço é responsável por realizar as integrações entre o TOTVS fluig e o Portal de Assinaturas.

Os endereços abaixo devem ser liberados no servidor de aplicação do TOTVS fluig para que as integrações sejam realizadas:

https://assinatura.homologwesign.com.br - Endereço do Portal de Assinaturas Homologação

https://portal.wesign.com.br - Endereço do Portal de Assinaturas Produção

Serviço Callback

O Callback é um serviço que avisa automaticamente seu TOTVS fluig quando acontece alguma ação no documento, como a assinatura de um participante. Ele ajuda a manter as informações do documento sempre atualizadas em tempo real. Ou seja, assim que o documento é assinado, o Portal de Assinaturas envia um aviso para que o status dessa assinatura seja atualizado na hora no TOTVS fluig.

Para seu funcionamento, é necessário que o endereço do TOTVS fluig público, ou seja, não necessite de acesso à uma VPN.

Usuário do Serviço Callback

Após a ativação do app Wesign na Central de Componentes, será criado um usuário chamado integration-1234-5678-9876-5432-X (X = código da empresa do fluig) no TOTVS fluig.

Ele é responsável por realizar as operações de atualização de dados do documento quando o serviço Callback é acionado pelo Portal de Assinaturas.

Para que o Callback funcione corretamente, é necessário incluir esse usuário no papel admin.

Datasets sincronizados

Se o seu ambiente não utilizar o Callback ou por algum motivo o serviço de Callback não notificar o TOTVS fluig, os dados dos documentos serão atualizados através do dataset ds_package_wesign.

Após a instalação do app, é recomendado que o dataset seja configurado para executar de forma sincronizado em um determinado intervalo de tempo que pode ser configurado conforme sua preferência.

Os datasets que podem ser sincronizados são:

  • ds_upload_wesign: Verifica todos os documentos com status de Enviando que não foram integrados e tentar integrar novamente.

    Este dataset irá verificar todos os documentos que não foram integrados e estão com status de Enviando. e tentará integrar novamente com o Portal de Assinaturas.

    Certifique-se sobre a necessidade de deixar esse dataset sincronizado para sua execução, uma vez que o remetente do documento ao não integrar (envio 1), pode realizar um novo envio e neste novo envio o documento ser integrado corretamente (envio 2), ficando o outro documento (envio 1) com status de Enviando.

    Quando o dataset for executado, ele tentará realizar a integração (envio 1) e isso pode causar "duplicidade" e gastos de créditos para um documento que já foi integrado em outro envio (envio 2).

  • ds_package_wesign: É o dataset responsável por atualizar o status do documento e gerar o manifesto de assinaturas. Sua lógica verifica se todos os documentos enviados nos últimos 3 meses e que estão status de Pendente foram assinados no Portal de Assinaturas.
  • ds_package_completo_wesign: possui o mesmo funcionamento do dataset ds_package_wesign, porém verifica todos os documentos com status de Pendente, independente da data de envio. Quanto mais documentos com o status de Pendente, maior será o tempo de execução do dataset.

Para configurar o agendamento do dataset, siga os passos abaixo. Para maiores informações, acesse Agendador de Tarefas.

  1. Acesse o Painel de Controle
  2. Acesse o Agendador de tarefas
  3. Clique em Adicionar
  4. Insira uma descrição e selecione a opção Sincronização de dataset
  5. Em Datasets, procure pelo dataset desejado
  6. Selecione a frequência de execução e clique em Confirmar.

Integração com fluxo de processo

É possível realizar uma integração entre um fluxo de processo com o app Wesign para realizar o envio de documentos de forma customizada.

Entre em contato com o Suporte Wesign para obter o código-fonte do fluxo de processo e formulário com as integrações.
