Manual do Usuário

Aprenda a usar as principais funcionalidades do AppDocs de forma simples e rápida

Upload de Documentos

O que é esta funcionalidade?

O sistema de upload permite que você envie seus documentos de forma segura e organizada para a plataforma. Suporta múltiplos formatos como PDF, DOC, DOCX e imagens.

Como utilizar:
1
Acesse a área de Upload
Clique no botão "Novo Documento" na tela principal
2
Selecione os arquivos
Arraste e solte ou clique para selecionar os documentos
3
Confirme o envio
Verifique os arquivos e clique em "Enviar Documentos"

Compartilhamento Seguro

O que é esta funcionalidade?

Permite compartilhar documentos com outros usuários de forma controlada, definindo permissões específicas como visualização, edição ou download para cada pessoa.

Como utilizar:
1
Selecione o documento
Localize e clique no documento que deseja compartilhar
2
Configure as permissões
Escolha o nível de acesso: visualizar, editar ou baixar
3
Adicione destinatários
Digite os e-mails das pessoas e envie o convite

Dicas Importantes

  • Mantenha seus documentos sempre organizados em pastas
  • Verifique as permissões antes de compartilhar arquivos sensíveis
  • Utilize nomes descritivos para facilitar a busca posterior
